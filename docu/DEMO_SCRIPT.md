# Three-minute demonstration script

Record only after validating the selected mode. Keep the provider badge visible throughout. If live Meta validation remains blocked, explicitly call the recording an offline prototype walkthrough, not a live Meta agent demo.

| Time | On screen | Narration |
| --- | --- | --- |
| 0:00–0:20 | Station dashboard and simulator/provider labels | “FieldFix helps a technician distinguish a frozen dashboard from a device that has stopped collecting data. This station and transport are software simulations.” |
| 0:20–0:45 | Reset transport mismatch; local reading changes while delivered timestamp ages | “The dashboard is stale, but that alone does not tell us where the break is.” |
| 0:45–1:35 | Investigate, show observed tool results and evidence references | “FieldFix compares local and delivered samples, reads device status and logs, and checks the publishing and subscription topics.” Name the actual provider mode. Only attribute tool selection to Meta if a genuine run is displayed. |
| 1:35–2:10 | Exact before/after proposal, approval, application | “This proposal changes one subscription topic. It is bound to this station, configuration version, and expiration. The technician approves the exact change.” |
| 2:10–2:40 | New delivered samples; verifier count reaches three | “A configuration write is not enough. Recovery requires three distinct post-repair samples, newer sequences, and a fresh latest sample.” |
| 2:40–3:00 | Actual validation report and limits | State the actual test count and completed live runs, including failures. “This is a local simulated station, not a real-world deployment or environmental safety judgment.” Identify work built during the hackathon. |

Do not invent impact metrics, customers, accuracy, usage costs, inference results, or deployment claims. Record the video locally; uploading and competition submission are participant steps.
